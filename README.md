# Inventory Comparison Report Guide

This guide explains how to interpret the inventory comparison report generated by the `files_comparer.py` script. The report is saved as an Excel file with the format `inventory_comparison_report_YYYYMMDD_HHMMSS.xlsx`.

## Report Tabs Overview

### 1. Summary Tab
This tab provides a high-level overview of the inventory comparison:
- **Total Items Vagaro**: Total number of items in the Vagaro inventory system
- **Total Items Reported**: Total number of items in the Stock Tracker
- **Items Missing In Stock Tracker**: Number of items that exist in Vagaro but not in Stock Tracker
- **Items Missing In Vagaro**: Number of items that exist in Stock Tracker but not in Vagaro
- **Items With Quantity Mismatch**: Number of items where quantities differ between systems
- **Timestamp**: When the report was generated

### 2. Missing in Stock Tracker Tab
This tab lists all items that exist in Vagaro but are not found in the Stock Tracker:
- **item_name**: Name of the missing item
- Use this list to identify items that need to be added to the Stock Tracker

### 3. Missing in Vagaro Tab
This tab lists all items that exist in the Stock Tracker but are not found in Vagaro:
- **item_name**: Name of the missing item
- Use this list to identify items that need to be added to Vagaro or investigated for potential errors

### 4. Quantity Mismatches Tab
This tab shows items where quantities differ between the two systems:
- **item_name**: Name of the item
- **quantity_vagaro**: Quantity in Vagaro system
- **quantity_reported**: Quantity in Stock Tracker
- **difference**: The discrepancy (Vagaro - Stock Tracker)
- **category_vagaro**: Category from Vagaro
- **category_reported**: Category from Stock Tracker

### 5. Full Comparison Tab
This tab provides a complete view of all items across both systems:
- **item_name**: Name of the item
- **quantity_vagaro**: Quantity in Vagaro
- **quantity_reported**: Quantity in Stock Tracker
- **difference**: The discrepancy
- **category_vagaro**: Category from Vagaro
- **category_reported**: Category from Stock Tracker
- Items with 0 in either quantity column indicate missing items in that system

### 6. Low Stock Analysis Tab
This tab focuses on inventory items that need attention:
- **Product Name**: Name of the item
- **Location of Stock**: Where the item is stored
- **Lot Number**: Lot/batch number for tracking
- **Quantity in Stock**: Current quantity (items with <10 units)
- **Expiration**: Expiration date
- **Days Until Expiration**: Number of days until the item expires
- **Daily Sales Goal**: Target daily sales
- **Monthly Sales Goal**: Target monthly sales
- **notes**: Any additional notes

## How to Use the Report

1. **Start with the Summary Tab**
   - Review the overall numbers to understand the scope of discrepancies
   - Note the total number of items in each system

2. **Check for Missing Items**
   - Review both "Missing in Stock Tracker" and "Missing in Vagaro" tabs
   - Prioritize investigation of items missing in either system
   - Add missing items to the appropriate system

3. **Investigate Quantity Mismatches**
   - Use the "Quantity Mismatches" tab to identify specific discrepancies
   - Look for patterns in the differences (e.g., systematic underreporting)
   - Update quantities in the appropriate system

4. **Monitor Low Stock Items**
   - Review the "Low Stock Analysis" tab for items needing attention
   - Pay special attention to items with:
     - Very low quantities (<5 units)
     - Expiring soon (within 30 days)
     - High daily sales goals

5. **Use Full Comparison for Detailed Analysis**
   - Use this tab for detailed investigation of specific items
   - Sort by various columns to identify patterns
   - Export filtered views for specific categories or locations

## Important Notes

- The Vagaro system is considered the source of truth for inventory quantities
- Items with negative differences indicate more items in Stock Tracker than Vagaro
- Items with positive differences indicate more items in Vagaro than Stock Tracker
- The Low Stock Analysis focuses on items with less than 10 units in stock
- Expiration warnings are triggered for items expiring within 30 days

## Troubleshooting

If you encounter issues with the report:
1. Verify that both input files are in the correct format
2. Check that the file paths in the script are correct
3. Ensure you have the required Python packages installed
4. Contact the system administrator if you need technical support
